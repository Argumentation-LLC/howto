# Subscribe or Redeem a Code

Creating an ordinary Argumentation.io account does not by itself enable saving and other account-based features. After creating the account, purchase an individual subscription or redeem an Argumentation.io code.

If you do not yet have an account, see [Create an Account](./create-account.html).

## Redeem a code

1. Sign in to your Argumentation.io account.
2. Open **Main Menu** and select **Redeem Code**.
3. Enter the redemption code when prompted.
4. Submit the code.

## Subscribe

1. Sign in to your Argumentation.io account.
2. Open **Main Menu** and select **Subscribe**.
3. Review the available plans and select the one you want.
4. Select **Subscribe** to continue to checkout.
5. Enter the requested payment and contact information.
6. If you have a promotion code, open the promotion-code field, enter the code, and apply it.
7. Confirm the subscription.

When Stripe asks for an email address during checkout, use the same address as your Argumentation.io account if possible. Using the same address makes the subscription easier to identify and manage.

The email address entered during checkout becomes the email associated with the subscription. It can differ from your Argumentation.io account email, but you will need to use the subscription email when requesting access to the customer portal.

Once the subscription or code is active, you can use Argumentation.io's saving, sharing, exporting, collaboration, and educational features.

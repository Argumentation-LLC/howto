# Organize Questions into Banks

A question bank is a reusable collection of questions. A quiz can draw a specified number of questions from a bank, allowing different attempts or students to receive different selections.

## Create a question bank

1. Open **Main Menu** and select **Banks**.
2. Select **New**.
3. Enter a name for the bank and confirm.

The **Banks** window displays question banks in its upper area and saved questions in its lower area.

## Add questions to a bank

You can drag a question from the lower area onto the desired bank. You can also:

1. Select the add command beside the bank.
2. In the **Add Questions** window, select the questions you want to include.
3. Select **Add**.

Use the disclosure control beside a bank's name to show or hide the questions it contains.

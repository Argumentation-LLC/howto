# Create and Publish Assignments

An assignment makes a quiz available to students in a particular class and controls its availability, attempts, scoring, and solution access.

## Create an assignment

1. Open **Main Menu** and select **Assignments**.
2. Choose the class from the **Classes** menu.
3. Select **New Assignment**.
4. Enter an assignment name.
5. Choose a quiz from the **Quiz** menu.
6. Set the opening and due dates.
7. Choose when solutions should be available: **Never**, **After Complete**, **After Submit**, or **After Graded**.
8. Choose whether to allow late submissions and multiple attempts.
9. If multiple attempts are allowed, choose whether the assignment uses the highest, most recent, or average score.
10. Select **Save and Publish**.

Selecting **Save** instead preserves the assignment without making it available to students.

### Solution timing

- **After Submit** makes solutions available after the student submits an assignment attempt, even if the student has attempts remaining.
- **After Complete** makes solutions available only after the student has used all available attempts.

Use **After Complete** when students should complete every permitted attempt before seeing the solutions.

## Share the assignment

Select the published assignment in the **Assignments** window, then select **Copy Link**. Send the link to students who have joined the class.

## Unpublish an assignment

Select the assignment and select **Unpublish**. Students can no longer begin the unpublished assignment.

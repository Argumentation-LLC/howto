# Share a Snapshot

A snapshot is a view-only image of a saved map that can be opened through a link. Use a snapshot when people should see the map without navigating or editing it.

## Create and send a snapshot link

1. Save the map and any changes you want the snapshot to show.
2. Open **Main Menu**.
3. Select **Share snapshot**.
4. Copy the link.
5. Send or submit the link where needed.

To download a file instead of creating a link, see [Export Maps as Images or PDFs](./export-maps.html).

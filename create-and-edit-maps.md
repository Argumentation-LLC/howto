# Create and Edit Maps

An argument map contains boxes connected by lines. The type and position of each box help represent its role in the reasoning.

Use the pages in this section to:

- Write in boxes
- Add main contentions, reasons, objections, other boxes, and co-premises
- Select boxes and navigate a map
- Delete, undo, and redo
- Move boxes and branches
- Change a box's type
- Create multiple trees on one canvas
- Apply color tags
- Work with the Scratchpad

# Collaborate in Real Time

Real-time collaboration allows several people to edit the same saved map. The person who enables collaboration is the host. People who open the collaboration link are guests.

When collaboration is enabled, the map is saved automatically. The host does not need to select **Save** after each change.

## Enable collaboration and invite guests

The map must be saved before collaboration can be enabled.

1. Open the map you want to work on together.
2. Save the map if it has not already been saved.
3. Open **Main Menu**.
4. Select **Enable Collaboration**.
5. Open **Main Menu** again and select **Share**.
6. Copy the collaboration link.
7. Send the link to the people you want to invite.

Anyone with the collaboration link can edit the shared map. Send it only to people you want to invite.

## Work together

Guests who open the link work on the host's saved map. Changes made by the host and guests appear in the shared map and are saved automatically.

## Save an independent copy as a guest

A guest with saving access can preserve an independent version in their own account:

1. Open **Main Menu** while viewing the collaborative map.
2. Select **Save as copy**.
3. Enter a name for the copy and confirm.

Later changes to this independent copy do not affect the host's map.

## Stop collaborating

The host can end access to the collaborative map:

1. Open **Main Menu**.
2. Select **Disable Collaboration**.

The map returns to manual saving, and the collaboration link no longer allows guests to edit the host's map. Save any further changes by selecting **Save**.

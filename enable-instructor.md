# Enable Instructor Features

Instructor features require an instructor redemption code. To request a code, email [argumentationcompany@gmail.com](mailto:argumentationcompany@gmail.com).

After you receive a code:

1. Sign in to your Argumentation.io account.
2. Open **Main Menu**.
3. Select **Manage Account**.
4. Select **Enable Instructor**.
5. Enter the instructor code and submit it.

Argumentation.io displays the message “Instructor mode enabled.” The instructor commands **Save as Question**, **Questions**, **Banks**, **Quizzes**, **Classes**, **Assignments**, and **Grading** then appear in **Main Menu**.

# Accessibility and Keyboard Use

Argumentation.io supports keyboard operation and use with screen readers. Keyboard commands make it possible to follow the logical structure of an argument map.

The pages in this section provide information on:

- [Using keyboard commands](./key_commands.html)
- [Using Argumentation.io with a screen reader](./Screen_Readers.html)

## Move through the interface

Use `Tab` and `Shift+Tab` to move among interactive parts of the interface, including toolbar controls, menu buttons, fields, and other controls. Press `Enter` to activate the focused control.

Argumentation.io also provides commands for navigating the structure of a map and performing frequent editing actions. See [Keyboard Commands](./key_commands.html) for the complete list.

Some menus use a combination of keys: open the menu with `Enter`, press `Tab` to focus its first item, then use the Up and Down arrow keys to move through the list and `Enter` to choose an item.

## Enlarge the interface

Use your browser's zoom feature to enlarge text, controls, and the rest of the interface. The zoom controls in Argumentation.io's View Panel change only the size of the map on the canvas.

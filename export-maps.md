# Export Maps as Images or PDFs

Export a map when you want a file that can be stored on your device, inserted into another document, printed, or uploaded elsewhere.

Argumentation.io can export a map in two formats:

- **PNG** is an image format. It is useful for slides, webpages, documents, and image uploads.
- **PDF** is a document format. It is useful for sharing, archiving, and printing.

## Export a map

1. Open **Main Menu**.
2. Select **Export as .png** or **Export as .pdf**.
3. If your browser prompts you, choose a filename and download location.

The exported file represents the map at the time of export. Later changes to the map do not update an exported file automatically; export it again to create an updated version.

To provide a view-only image through a link instead of downloading a file, see [Share a Snapshot](./share-snapshot.html).

# Save and Load Maps

Saved maps are stored in your Argumentation.io account. A saved map includes its boxes, connections, text, color tags, and Scratchpad content.

Saving requires an account with an individual subscription, institutional access, or a redeemed Argumentation.io code.

## Save a new map

1. Open **Main Menu**.
2. Select **Save** or **Save as**.
3. Enter a name for the map.
4. Select **OK**.

After a map has been saved, use **Save** to save further changes to the same map.

## Save a separate copy

Use **Save as** when you want to preserve the current saved map and create another saved map under a new name.

1. Open **Main Menu**.
2. Select **Save as**.
3. Enter a name for the new map.
4. Select **OK**.

## Load a saved map

1. Open **Main Menu**.
2. Select **Load**.
3. Find the map you want to open.
4. Select the command for loading that map.

The selected map replaces the map currently displayed in the workspace. Save changes to your current map before loading another map if you want to keep them.

## Delete a saved map

Open **Main Menu**, select **Load**, and use the delete command beside the map you want to remove.

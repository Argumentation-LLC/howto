# Writing in Boxes

Argumentation.io lets you write in main contention, reason, objection, other, and inference boxes.

## With a mouse or touchscreen

Select the text area inside a box, then enter or edit its text.

## With a keyboard

1. Select the box you want to edit.
2. On Windows, press `Shift+Alt+Enter`. On Mac, press `Shift+Option+Enter`.
3. Enter or edit the box's text.
4. Press the same key command again to leave text-editing mode and return focus to the box.

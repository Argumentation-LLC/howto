# Getting Started

Argumentation.io is an application for creating, editing, saving, and sharing argument maps. An argument map represents claims as boxes and shows logical relationships with connecting lines.

Begin with these pages:

- [Explore the Argumentation.io Workspace](./workspace.html) introduces the canvas, toolbar, Main Menu, information panel, Scratchpad, and View Panel.
- [Main Menu](./main_menu.html) explains the commands available from the Main Menu.
- [Create an Account](./create-account.html) explains how to create an account and how account access affects available features.

To begin building a map, continue to [Create and Edit Maps](./create-and-edit-maps.html).

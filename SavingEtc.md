# Save, Share, and Export Maps

Argumentation.io provides several ways to preserve a map or make it available to someone else. Choose the feature that matches what you want to do.

| Goal | Feature |
| --- | --- |
| Keep a map in your Argumentation.io account | **Save** or **Save as** |
| Give someone an independently editable version | **Share** |
| Provide a view-only image through a link | **Share snapshot** |
| Edit the same saved map with other people | **Enable Collaboration** |
| Download an image or document file | **Export as .png** or **Export as .pdf** |

Saving, sharing, collaboration, and exporting require an account with an individual subscription, institutional access, or a redeemed Argumentation.io code.
